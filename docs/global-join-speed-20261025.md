# 全球资料新增与投票图片加载优化

日期：2026-10-25。状态：用户已明确授权同步与性能优化上线。本次发布基于 68f081c；最终部署版本与实测记录见工作区 06-delivery/releases/global-speed-20261025/STATUS.md。

## 已确认原因

- `/join` 是自由输入的 datalist，但默认值“中国”使浏览器只展示包含“中国”的建议，误导用户以为不能选择英国。后台没有国家白名单限制。
- 群码原先在投票后串行请求配置，再下载图片并等待 decode，展示时重新设置网络 URL；响应为 no-store，会产生重复加载机会。
- com 的动态图片经 xyz 回源。以下是本机一次公网 GET 样本，非全球网络基准，不代表英国用户的实际耗时：

| 资源 | 大小 | com 总耗时 | xyz 总耗时 |
| --- | ---: | ---: | ---: |
| 当前群码 PNG | 72,777 B | 4.30 s | 0.12 s |
| 深圳新海报 941px WebP | 306,822 B | 40.56 s | 0.19 s |
| 深圳新海报 640px WebP | 161,132 B | 10.67 s | 0.08 s |

com 群码配置请求另耗时 3.20 s；xyz 0.31 s。未记录群码内容、个人资料或凭据。

## 本地修改

- 国家初始为空，支持 249 个国家/地区的中英文建议，英国靠前；仍允许填写未列出的名称。无 Intl.DisplayNames 的旧浏览器保留基础建议与自由输入。
- 团体、个人的“所属学校”移到主表单，明确选填，未收录名称可直接提交。改国家清除旧目录编号，避免沿用之前的学校关联。审核与隐私设置保持。
- 初次投票页响应携带当前群码配置并提前加载；投票响应再携带即时配置，无需成功后单独请求配置。用内存 Blob 复用已下载图片与保存入口，关闭后不重复下载；切换版本、停用、到期清理旧图。
- 弹窗先显示加载状态，失败可重试；仍只在投票成功后自动弹出，同浏览器同版本一次。手动点击立即打开弹窗，30秒内复用刚取得的配置，过期则在弹窗加载过程中校验；后台私有预览仍需登录。配置与私有图 no-store，公开当前版本群码采用最长30秒缓存（不超过失效时间）和ETag。停用/换码在源站立即生效，已有边缘/浏览器缓存最长30秒失效，不把已经公开下载的图片当成可撤回数据。
- 海报从当前配置设置 srcset 后再设置 src；不再同时下载 HTML 旧图与后台新图；隐藏确认/意见弹窗不预先加载默认图。当前城市优先，手机非当前城市延迟加载。配置失败时才显示内置默认海报。
- com Nginx 配置新增仅 `/api/media/` 的公共海报缓存，256MB 上限、并发回源锁；普通 API 明确 proxy_cache off。公开版本群码另设32MB/30秒短缓存和条件回源；投票、评论、配置和后台接口不缓存。静态图片浏览器缓存7天，换图使用版本URL。部署脚本创建缓存目录，按既有流程执行 nginx -t 后 reload。

## 必要验证

- 6 项群码 HTTP 检查和 5 项资料 HTTP 检查通过，包括英国 school/group/person 自由名称提交、待审核、群码切换/停用/到期/权限、投票成功返回新配置。一次 Windows 本地连接中止导致 auth 检查报错，单独重跑该项通过。
- 4 个修改的前端脚本通过 node --check；后续按钮与弹窗修改重新通过语法检查。公开群码304、停用后拒绝条件请求、TTL不越过失效时间、私有预览不缓存均通过。
- 本地浏览器显示 249 个建议；能填写英国、Southampton 和 University of Southampton，无需已有学校编号。
- 合成投票成功自动弹窗：成功阶段只新增 vote 与群码事件请求，群码图片没有再次下载。手动打开也复用图片。
- 浏览器阻断本地群码请求后显示重试；解除阻断后重试正常。无生产投票、上传或资料提交。
