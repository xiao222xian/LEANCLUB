# 投票视觉重修与飞书通知 · 本地验收

日期：2026-10-22。用户否定米色确认框、箭头及说明堆叠，要求大胆的健身品牌视觉、图片背景、标识、居中对齐，并增加飞书群机器人通知。此记录覆盖当前 LEANCLUB Python/SQLite 站点，不涉及芋道或小程序。视觉实现不等于用户审美认可；尚未公开部署。

## 设计与内容

- 延续已批准的三张站姿薄肌海报，三张原始 WebP 未改动；桌面整屏三联，手机单张切换。城市标题、操作与标签居中对齐；使用亮黄绿标记主要动作和选中状态。
- 确认弹窗改为整幅城市影像，品牌标记随标题放在人物下方，避免覆盖面部。移除装饰箭头、IP 解释、重复免责声明；服务端去重规则继续执行。取消、Escape、遮罩关闭均不提交。
- 新增原创代码矢量 LC 标记和静态颗粒纹理；不宣称注册商标或正式 VI。人物素材沿用批准版本，未重新生成或下载第三方摄影。素材记录及 SHA-256 已更新。
- 主页活动入口同样使用三联影像、居中短标题与单一主按钮；标题独立置于摄影背景带，避免压住珠海人物。手机默认图另作面部焦点适配；自定义图和手工焦点保留。
- 管理台增加运动摄影标题区、品牌标识及“飞书通知”页。数据表单保持可读的浅底，登录页使用摄影／石墨色；移除装饰箭头。

## 通知行为与测试

详见 [飞书通知说明](feishu-notifications.md)。管理员可保存 Webhook、可选签名密钥、开启／暂停、测试及重试失败任务。地址和密钥不完整回显；输入框保存后清空。有效新增与改投在同一数据库事务写入待发队列，携带当次操作之后的三城票数快照；重复提交不产生事件。

后端全套 **82 项测试通过（31.010 秒）**，含新增 20 项飞书测试：允许域名、阻止跳转、签名、权限／CSRF、脱敏、持久队列、并发／重复、失败退避、重启恢复及配置变更。后端编译、前端 Node 语法和 diff 检查通过。

独立浏览器测试使用 4182/5383、`data/editorial-feishu-qa-20261022/site.sqlite3` 与合成账号，未把测试票或机器人配置写入用户运行库。测试发送使用临时捕获函数，且禁用测试进程的真实 HTTPS 传输：

| 实际操作 | 实测结果 |
| --- | --- |
| 开启但没有地址 | 前端要求填写，不提交 |
| 保存非飞书域名 | 服务端拒绝，不保存或发送 |
| 保存合成飞书地址并暂停 | 状态为已配置／已暂停；刷新后地址输入为空 |

最终 QA 捕获恰好 3 条消息（测试、新票、改投）。没有向真实飞书群发送消息；真实 Webhook 连通、签名／关键词及群内显示需用户配置后测试。

## 用户运行环境

更新前在线 SQLite 备份为忽略目录内 `data/backups/pre-feishu-20261022-2ad48bf1.sqlite3`。已使用原 `data/local.sqlite3` 重启 4180/5381 后台服务，保留账号、原广州 1 票及海报；未初始化或重设账号。用户库飞书默认未配置，通知关闭。QA 模拟服务在验收后停止，合成 Webhook 清除，避免后续误发送。

已发现本轮 QA 管理登录与用户站点共用 `127.0.0.1`，浏览器 Cookie 不按端口隔离，测试登录覆盖了原后台会话 Cookie。最终后台需要用原账号重新登录一次，密码与数据库账号未改。后续浏览器 QA 应使用 `localhost` 等独立主机名或独立浏览器配置；不能把不同端口视为 Cookie 隔离。

同一碰撞也影响匿名投票 Cookie。已在确认用户库仅有原广州 1 票、当前页面新签发的唯一最新浏览器标识后，以 SQLite 事务恢复这张票与当前浏览器的归属及 IP 关联；票数、城市和时间不变，外键检查通过，浏览器重新加载实际恢复改投按钮。修复前另存 `data/backups/pre-local-cookie-repair-82b8f587.sqlite3`。这是本机联调事故修复，不新增任何公网认领接口或放宽 IP 规则。默认打开手机投票页时现会直接展示已投城市，带明确城市参数的海报入口仍展示参数对应城市。

飞书网络异常不影响计票；超时后的重试有重复送达同一事件的可能，消息中有固定事件编号。生产 HTTPS、反向代理、真实手机微信／扫码及真实群验证仍不属于此次本地验收。
