# 留言区简化 · 2026-10-24

用户认为原留言区 AI/模板感明显，要求减少文案并做得简洁。已在现有本地实现上调整，没有更改评论数据和公开范围，也没有部署到公网。

## 改动

- 去掉两行大口号、介绍段、重复说明、装饰引号和多层卡片，标题只保留“留言”和真实数量。
- 桌面为输入区与细线留言列表；手机为单列。昵称与城市收进可展开选填项，公开展示/弹幕同意仍直接可见且默认不勾选。
- 墨绿底配低饱和黄绿按钮。正文 15px，手机输入 16px；昵称 13px，次要操作至少 12px，增加弱文字对比度。
- 保留刷新、分页、240 字限制、幂等与失败重试、文字安全渲染、隐藏/恢复同步、弹幕开关/去重/减少动态，以及原私密意见入口。
- 资源查询版本更新到 `20261024-comments-v2`。首页滚动区未改。

文件：`web/creator/city-vote/index.html`、`comments.css`、`comments.js`，对应 `tests/test_public_comments_client.cjs`。

## 验证

- Node 评论客户端回归通过：同意、Unicode 长度、身份初始化、幂等、XSS 文本、分页、隐藏刷新、弹幕去重、减少动态/可见性等；补充真实计数与昵称错误展开场景。
- 活动、会员客户端回归通过；JavaScript 语法及 Git diff 空白检查通过。本轮不涉及后端变更，未重跑或声称新增生产后端验收。
- 浏览器 1280px 桌面和 390px 手机实际查看，横向溢出为 0；昵称/城市展开可见，空留言阻止提交，私密意见弹窗可打开/关闭。没有新增测试留言或改投，没有删除用户既有留言。
