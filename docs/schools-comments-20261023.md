# 首页选校与投票页公开讨论

日期：2026-10-23（Asia/Shanghai）。范围：本地代码与本机运行服务；未部署生产。

## 用户要求与本轮边界

接通首页学校搜索和学校目录，为投票页增加评论区与弹幕。用户随后明确暂停首页底部滚动内容改造，因此原校徽和人物滚动区的内容、视觉保留，本轮未发布新的 CMS 内容。

## 已实现

- 首页内联建议使用与 `/schools` 相同的高校接口，显示实际总数、地区、学校层次与俱乐部状态。选中后携带 `schoolId` 打开现有详情；普通搜索提交进入完整结果。支持中文输入法、键盘、空态、失败重试和迟到请求隔离，手机浮层避免 hero 裁切。目录收录不代表已有俱乐部或完成学籍认证。
- 投票页保留三城摄影首屏，下方增加公开讨论区。正文 2–240 字，昵称与城市选填；发布前须主动勾选同意公开并用作弹幕。持久化、幂等重试、限频、游标分页接入现有 Python/SQLite 服务。
- 弹幕来自公开留言，并穿插明确标为“官方话题”的讨论邀请。不伪造昵称、用户发言、时间或参与量。同一留言同时最多出现一次，当前官方话题也不重复；两行最多六条。支持关闭、系统减少动态效果、页面隐藏与离屏停止。
- 原芋道「薄肌运营 → 城市投票」增加公开评论列表、筛选及隐藏／恢复；复用已有意见查询/管理权限及签名运营桥接。隐藏评论退出公开接口，已打开页面在下次刷新（可见时每 30 秒自动刷新）移除列表及弹幕。
- 原私密意见箱仍只供团队查看，历史私密意见没有迁入公开评论。公开评论不创建飞书通知。

接口见 [评论接口](campaign-comments-api.md)。内部 `leanclub` 标识保持兼容。
