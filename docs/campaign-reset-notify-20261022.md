## 用户要求与数据处理

- 用户指定重置现有管理员、清空测试记录、配置机器人，并明确授权向该群主动发送一次当前汇总。
- 停止本机服务后，使用 SQLite backup API 完整备份到私有 `data/backups/pre-vote-reset-20261022-171952-af6f9d4e.sqlite3`。该文件不提交 Git；恢复之前须先停止服务并核对机器人设置，避免恢复旧队列后误发。
- 清除 1 票、1 条 IP 占用、11 条访问事件、4 条匿名访客、1 个管理会话、50 条限流记录；旧通知队列为 0。之后的正常登录会重新产生会话与限流记录，不属于残留测试数据。
- 在同一事务中重置唯一管理员及盐化密码摘要，撤销旧会话。凭据只在私有运行库中保存；不在文档、源码或前端写入真实密码，不改首次初始化的通用密码规则。
- 保留学校相关表、三城默认海报、海报配置与历史及投票 IP 随机密钥；检查外键无异常。该库的学校表及自定义海报记录原本均为 0，未将其误写为已有业务内容。
- 用户给出的机器人地址仅保存到忽略提交的运行库，开启自动新增通知，不回显真实地址。

## 通知规则

仅新增有效票自动入队；改投更新现有票但不通知，重复提交和取消确认不通知。下一次新增通知和手动汇总包含最新三城分布。旧版尚未发送的改投任务停止发送。

新增手动汇总接口与后台按钮，即使暂停自动通知也可使用。消息为飞书卡片，区分新增、汇总及连接测试，突出总票数与三城分列数字，附北京时间。定时汇总只是后续方向，本轮没有建立计划任务。
