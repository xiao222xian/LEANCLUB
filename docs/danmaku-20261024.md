# 城市投票弹幕调整 · 2026-10-24

## 实现

- 将24条鼓励、宣传和提问文案替换为48条短句，使用城市应答、约时间、新手顾虑、找搭子等日常表达，保留少量「+1」「蹲蹲」等短回应。
- 每轮打乱顺序，48条播放完成后才开始下一轮；切换弹幕开关不重置轮次，同时避免上一句在轮次交界和屏幕内重复。
- 真实留言仍从 `/api/campaign/comments` 读取，原内容、来源和后台审核联动保留。点缀短句只在浏览器显示，不创建账号、留言记录或数量。
- 保留桌面68px/s、窄屏56px/s的速度、2.2秒发射节奏、两轨和最多6条的限制；后台标签页、离屏、系统减少动态效果时停止动画。
- HTML引用更新为 `comments-v3`，避免继续命中旧脚本缓存。

## 双域发布

- `leanmuscleclub.com` 和 `boji.tensorbot.xyz` 使用同一个已提交版本，com仍经代理使用152.136.108.87的公共API和数据库；留言、投票、学校资料不复制成两份。
- 删除com发布脚本对备案脚本的单独改写，两边使用同一份按域名判断的代码。com不显示旧备案号，已核验的xyz保留自己的备案号；canonical等域名元信息按各站实际地址生成。
- 本次仅发布网站，不迁移或清空数据库，不替换Java/Vue后台或证书。增量发布状态通过manifest记录是否变更表结构，不再把所有后续发布误标成学校数据迁移。
