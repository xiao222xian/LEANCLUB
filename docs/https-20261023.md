## 更新与回退

证书更新时先检查完整链/域名/有效期/私钥匹配，备份现用证书与配置，仅在服务器安全目录替换，执行 nginx -t 后 reload，再用正常CA验证公网HTTPS。初次切换脚本 `deploy/ubuntu/enable-uploaded-https.py` 有已启用保护，不是续期脚本，不应重复执行。

紧急撤销本轮配置时，从上述root私密备份成对恢复nginx与env，执行nginx -t、重启bojizhuye并reload nginx，再验证HTTP健康。回退不恢复数据库、不更换current；此操作会回到加密前配置，只用于明确决定撤销HTTPS时。常规版本回退应继续保留现有HTTPS配置。
