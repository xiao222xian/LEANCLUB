# 飞书定时投票汇总与实时评论

2026-10-26，本地实现并通过46项相关检查；用户已确认更新服务器，正在准备发布。

- 投票：北京时间每天08:00、13:00、18:00、22:00发送当前深圳、珠海、广州票数及总票数。没有变化或为零也汇总。
- 评论：新增公开留言及回复实时异步推送；原有私密意见实时提醒保持。
- 新投票、改投、重复提交、取消确认不触发实时票数通知。手动立即汇总仍可用。
- 沿用当前机器人、开关、签名、持久队列与失败重试。增量新增调度游标表，不清理业务数据；取消未完成的旧单票/改投任务。
- 固定UTC+8，后台工作线程调度，无需浏览器保持打开。重启/并发同一时点只建一次任务；意外停机仅补最近一个错过时点的当前汇总，暂停期间跳过。
