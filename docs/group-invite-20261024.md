# 投票后活动群二维码

2026-10-24：用户已查看本地效果并明确同意推送上线。本次发布功能代码，演示库与演示二维码不进入生产；最终发布提交和双域验收记录在工作区 WORKLOG 及 06-delivery/releases/group-invite-20261024/STATUS.md。

- 公众弹窗：投票成功后自动打开，同一浏览器/二维码图像版本仅自动展示一次，关闭后有「加入活动群」入口。使用白底、薄荷绿、居中二维码；文案「一起运动，群里见。」；桌面居中、窄屏靠底，支持关闭、遮罩、Esc和键盘焦点恢复。
- 网站管理 `/legacy-admin#groups`：多图列表、备注、上传/替换、预览、设为展示、停用、删除、可选失效时间。最多30张，活动配置的单一外键保证同时仅一张；版本校验避免并发覆盖，展示中的图片须先停用再删除。
- SQLite增量表 `campaign_groups` / `campaign_group_config` / `campaign_group_events` / `campaign_group_audit`；与现有投票共库，两域发布后读取同一配置。首次上线无活动群二维码，管理员上传并「设为展示」后才会向访客显示。
- 管理读写复用原会话、CSRF、Origin；图片仅允许PNG/JPEG且重新编码为无元数据PNG，不裁切或有损压缩二维码。备用图仅管理员能读；公众图片在切换、停用、替换或到期后返回404，配置与图片不缓存。
- 公众仅记录展示、保存点击事件，重试事件去重，不记录入群人数。二维码获取/图片失败不会回滚或阻塞投票；未配置/到期则隐藏入口，不自动回退到其他备用群。
- 新功能4项HTTP检查通过：认证/CSRF/私有图、单一展示/并发/删除保护、到期/计数幂等、无效图片/替换版本。只做相关JS语法和本地浏览器投票→自动弹窗、后台编辑、390px预览，未跑无关全量测试。

本地预览：`http://127.0.0.1:4230/city-vote`，后台 `http://127.0.0.1:4230/legacy-admin#groups`。独立API5430，数据库data/group-invite-preview.sqlite3；测试二维码指向example.invalid，不是真实微信群。不能将此演示库当作生产配置。
