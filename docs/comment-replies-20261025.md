# 公开留言与连续互动

日期：2026-10-25。用户已确认后台回复预览，并要求补齐用户间互动后同步上线。具体发布 SHA 和双域验收记录见工作区 `06-delivery/releases/comment-threads-20261025/STATUS.md`。

## 使用方式

- 投票页每条留言、楼内回复、主办方回复旁均可点击「回复」。楼内显示回复对象，支持继续对话，保持单层排版。
- 默认展示每楼最早 3 条回复，其余按需加载；每次最多 20 条。无需短信登录，昵称选填，必须明确同意公开展示。
- 发送后直接显示服务器确认的回复；失败保留输入并安全重试。刷新与轮询保留正在编辑的内容及已展开楼层，页面隐藏或失焦暂停后台刷新。
- 轻量后台 `/legacy-admin#comments` 新增「公开留言」，可筛选全部、待回复、已回复及可见性。所有用户跟帖也进入管理列表，附父留言引用。
- 后台可对每条用户留言发布、修改、撤回一条「薄肌学院」回复。隐藏根留言会隐藏整楼；隐藏单条楼内留言不会删除其他回复，其被引用昵称显示为「已隐藏的留言」。
- 私密意见不转成公开内容。顶部弹幕仅使用根留言；楼内用户回复仍复用现有 comment 群通知，主办方回复不另发通知。
- 前台数字为根留言数，每楼单独展示/展开回复；后台列表包含根留言和跟帖。前台可见时约 30 秒刷新，可手动刷新，不是即时聊天或登录用户消息中心。

## 数据与接口

继续使用共享 Python/SQLite 评论数据，不建第二份数据库。启动事务增量添加 `reply_content/reply_updated/reply_revision/root_id/parent_id/reply_to_official` 及索引，旧根留言回填自己的 root_id，保留原数据。

- `POST /api/campaign/comments` 原格式新增可选 `parentId`、`replyToOfficial`；根由服务器根据目标推导，不能伪造跨楼或官方身份。公开昵称不可冒用薄肌学院/LEAN SCHOOL。
- 公共根列表每项含 `replies/replyCount/repliesNextCursor`；`GET /api/campaign/comments/{rootId}/replies?limit=20&cursor=...` 按时间/id 升序读取楼内评论。
- 公共投影含 `rootId/parentId/replyToName/replyToOfficial/reply`。管理员列表另含父文本预览、状态与回复版本；公共 POST 回执不包含管理员上下文或版本。
- `GET /api/admin/comments?status=all&reply=all&page=1`、`POST /api/admin/comments/{id}/reply`、`POST /api/admin/comments/{id}/status` 使用现有管理员会话；写入要求同源和 CSRF。
- 官方回复 `{content, revision}`，明确 `content:null` 为撤回；版本冲突返回409，防止多人编辑覆盖。文本使用 textContent 渲染，用户评论2–240字、官方回复1–500字。
- 根留言限额保持原值。楼内回复独立限额：访客12条/10分钟、60条/日，IP60条/10分钟、300条/日；重复请求不重复入库、通知或扣额度。
- 既有 Java 运维桥查询/隐藏仍兼容，本轮管理入口是轻量内容后台，未扩展 Java 管理页面。
