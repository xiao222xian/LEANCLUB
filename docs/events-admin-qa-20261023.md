# 活动管理与现场核销 UI 验收

日期：2026-10-23（北京时间）。环境为本地隔离站点 `http://127.0.0.1`，数据保存在忽略目录 `data/events-qa-20261023/`。本文只记录这一轮真实操作与有限检查，不代表线上或真机相机验收。

## 实现范围

- 管理台新增「活动报名」，保留原数据概览、意见箱、城市海报、飞书通知。
- 创建草稿、编辑内容与价格、选择现有城市海报、发布、停止报名、重新开放、取消活动。发布与取消分别有二次确认；收款渠道不可用时发布说明明确只开放详情，暂不接受订单。取消活动明确已付款转待退款，不声称退款资金已完成。
- 报名与订单名单、支付六状态统计、有效报名/剩余名额/核销统计，分页及状态筛选。完整手机号仅管理接口可见，UI 默认脱敏，按需显示后可再次隐藏。
- 独立 `/check-in`，沿用管理员会话和 CSRF。扫码链接位于 fragment，先核对详情、工作人员点击确认后才写核销；显示重复原核销时间，不能重复放行。
- HTTP 环境保留票号/票码链接输入，不虚构网页相机可用。仅 secure context、媒体设备与 QR BarcodeDetector 均可用时显示相机入口；点击才请求权限，关闭、隐藏页面和离开时停止 tracks。
- 无手动“已收款”或“已退款”开关，无真实支付、退款、推送操作。

## 验收边界

- 桌面 Edge 使用宿主 90% 页面缩放，设置 viewport 351×760 后 DOM 为 390×844 CSS 像素；288 宽对应 CSS 320。宽度记录以 DOM 为准，图片输出像素不当作设备像素。
- 后台移动截图工具两次超时，因此只记录移动 DOM 宽度与实际操作，不声称移动截图已成功。核销移动截图保存成功。临时尺寸覆盖已恢复，验收专用浏览器 tab 已关闭。
- 未在浏览器操作 20 条以上的真实分页数据，未测试手机实际相机权限/实时识码、微信系统扫一扫、离线网络和并发核销；原子性由后端独立测试负责，不能以 UI 截图代替。
- 内嵌工作人员登录 UI 已实现；本轮核销页复用了已登录管理员会话，未将独立未登录深链整套操作记为已测。
- 真实商户收款、微信支付/支付宝和实际资金退款尚未验收。本地测试支付适配器只存在忽略目录，未加入生产前端或收款按钮。
