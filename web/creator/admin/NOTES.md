# LEAN SCHOOL 内容管理前端

入口 `/admin`。原生 HTML / CSS / JavaScript，同源请求，无 CDN 或运行时依赖。

## 已实现

- 初次加载读取 `/api/admin/session`，按服务端状态显示登录、允许本机初始化的表单或服务器初始化提示。密码只用于当前请求，CSRF Token 仅保留在内存。
- 用户名与密码支持密码管理器、显隐、重复提交锁及错误恢复；登录到期自动回到登录页。账号创建不会使用固定或演示凭据。
- 数据概览展示真实总票数、三城比例、主站累计/今日浏览与独立浏览器数、投票页流量、14 天趋势。可见概览每 10 秒自动更新，焦点/可见状态恢复和投票成功广播也触发刷新；隐藏页面不轮询。折叠表格提供对应的每日数值；没有模拟票数。
- 海报先本地检查 MIME / 8 MiB 大小并解码预览，选择不会提交。点击“发布海报”才发原始 File 数据；错误保留待发布文件。当前在线与待发布预览可切换。
- 焦点滑条即时预览、单独保存。若有待发布新图，先发布后再保存构图。恢复默认需在卡片内再次确认。
- 三个海报可分别编辑；写入期间锁定对应卡片，刷新/退出不会打断提交。带未发布图片/未保存构图离开页面时使用浏览器原生提醒。
- 视图切换支持左右方向键、Home、End；状态有辅助技术通知；趋势图附文字摘要和表格；尊重减少动态效果设置。
- 飞书通知支持保存 Webhook、可选签名密钥、开启/暂停、发送测试消息和重试失败消息。已保存凭据不回显；输入留空保留，密钥可显式移除，更换机器人时后端清除旧密钥。配置有未保存更改时禁用测试与重试，避免向错误群发送。
- 发送请求只提示已入队，最终结果读取后台状态；通知页可见时空闲每 10 秒刷新、有待发送消息时每 3 秒刷新。后台轮询不覆盖正在填写的表单，不抢走焦点；切换页面、隐藏、退出与会话失效停止轮询。会话失效清理配置状态和凭据输入。
- 视觉更新为石墨黑白与酸青色，登录使用已批准的广州影像；管理页使用三城图带和居中标题。移除装饰箭头、常驻 IP 说明，保留有必要的字段标签与统计口径。

## API 与资源

遵循 `backend/campaign_http.py` 的 `/api/admin/*` 契约；发送 Cookie 的同源 fetch，所有 POST 带 `X-CSRF-Token`。接口错误以纯文本显示，不渲染用户 HTML。海报仅接受同源 URL。

- 字体 `/city-vote/assets/fonts/sans.ttf`
- 默认海报 `/city-vote/assets/{shenzhen,zhuhai,guangzhou}.webp`
- 品牌标记 `/city-vote/assets/lean-emblem.svg`
- 飞书配置 GET/POST `/api/admin/feishu`，测试 POST `/api/admin/feishu/test`，重试 POST `/api/admin/feishu/retry`
- 跳转主站 `/`，投票页 `/city-vote`，城市链接 `/city-vote?city=...`

## 验证边界

本轮前端通过 Node JavaScript 语法与 Git diff 空白检查；HTML 73 个 ID 唯一，静态直接 ID 引用全部存在，文件无替换乱码字符。真实会话、API 集成和桌面/手机浏览器验证由主任务统一执行；前端开发未向真实飞书群发送消息。此文件不将静态实现记录为已完成生产部署、机器人实际送达或用户审美验收。
